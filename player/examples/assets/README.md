# Example scene

The optional Jensen 2M example is downloaded from the standalone
[FTGS Player](https://opsiclear-4dgs.github.io/ftgs-player/). This bundled player
contains its metadata and saved camera, without duplicating the 45 MB result.
Local files and the generated ribbon demo work offline once the player is served.

`site/assets/social-preview.jpg` is the bundled 1200×675 thumbnail of the same
retained 2M scene at normalized time 0.3, using its saved camera. The X card's
player URL opens the interactive 4DGS web app with the full TSOG and its audio.
The thumbnail retains the source media's original rights.

[Original result, checksum and media attribution](https://github.com/OpsiClear-4DGS/ftgs-player/blob/main/examples/assets/README.md).
