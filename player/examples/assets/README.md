# Example scene

The optional Jensen 2M example is downloaded from the standalone
[FTGS Player](https://opsiclear-4dgs.github.io/ftgs-player/). This bundled player
contains its metadata and saved camera, without duplicating the 45 MB result.
Local files and the generated ribbon demo work offline once the player is served.

The small `jensen-preview.mp4` and `site/assets/social-preview.jpg` are bundled
for the social-card player. They are a five-second, 960×540 H.264/AAC render
with the original audio and a 1200×675 still from the same retained 2M scene.
The X card is a linear video preview; the linked page opens the interactive
scene. Source media and audio retain their original rights. Regenerate the
preview using `tools/render-social-preview.py` in the standalone repository,
which retains the full TSOG and its saved camera.

[Original result, checksum and media attribution](https://github.com/OpsiClear-4DGS/ftgs-player/blob/main/examples/assets/README.md).
